# Утверждения плана без подтверждения в базе знаний

91 формулировок из маршрута, которых нет в 70 статьях wrenjapan — ни за, ни против. Получено сверкой по агенту на день (workflow `verify-days-against-kb`).

**Это не список ошибок.** Отсутствие подтверждения не делает факт неверным: справочник просто не обо всём пишет. Но это ровно те места, которые держатся на общих знаниях модели, а не на источнике владельца проекта — и если какое-то решение упирается в такой пункт, его стоит проверить самостоятельно.
