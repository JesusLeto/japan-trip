# Провенанс координат маршрута

Откуда взялась каждая точка на карте: запрос к Nominatim и `display_name` из ответа. Нужен, чтобы любую координату можно было перепроверить, не доверяя на слово. День 1 добавлен вручную из ссылок Google Maps, присланных владельцем проекта.

Пешие и автобусные трассы — OSRM FOSSGIS (`routed-foot` / `routed-car`). Рельс, канатка и паром — без геометрии.
