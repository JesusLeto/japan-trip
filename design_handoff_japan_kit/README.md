# Handoff: JAPAN KIT — планировщик путешествия в Японию

## Overview
Одностраничный личный планировщик 10-дневного путешествия Токио → Хаконэ → Киото → Нара → Осака. Три рабочих инструмента на одной странице: чеклист подготовки «До вылета», чеклист «Сразу по прилёту» и детальный маршрут по дням на интерактивной карте (Leaflet + OpenStreetMap). Прогресс сохраняется локально (localStorage). Язык интерфейса — русский.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, созданные в HTML**: прототип, показывающий целевой внешний вид и поведение, а не production-код для прямого копирования. Задача — **воссоздать этот дизайн в целевой кодовой базе** с её паттернами и библиотеками. Если кодовой базы ещё нет, рекомендуемый стек: **React (Vite) + Leaflet (react-leaflet или прямой API)** — прототип уже структурирован как React-подобные компоненты, перенос будет почти 1:1.

- `JAPAN KIT.dc.html` — весь UI (разметка + логика в классе `Component`; методы аналогичны React class component, `renderVals()` — аналог render-пропсов).
- `data.js` — вся модель данных (`window.JK_DATA`): чеклисты и маршрут. Переносится как есть в виде константы/JSON.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, состояния и копирайтинг — финальные. Воспроизводить пиксель-в-пиксель.

### Типографика
Без внешних шрифтов. Два стека:
- Основной: `system-ui, -apple-system, 'Segoe UI', sans-serif`
- Моно (метки, счётчики, номера секций, времена): `ui-monospace, 'SF Mono', Menlo, Consolas, monospace`

Шкала:
- H1 хиро: 62px / 1.06, weight 700, letter-spacing −0.02em (38px на мобильном)
- H2 секции: 34px / 1.15, weight 700, letter-spacing −0.01em; ключевое слово — `<em>` курсивом цветом accent
- Номер секции `/ 01`: моно 12px, letter-spacing 0.12em, цвет text-faint, над заголовком
- H3 категории: 14px, weight 600, uppercase, letter-spacing 0.06em
- Подзаголовок хиро: 18px / 1.6, text-muted
- Пункт чеклиста: 14.5px / 1.4
- Описания/попапы: 12.5–13.5px / 1.55–1.65
- Метки (дедлайн, счётчики, транспорт): моно 11–12px

### Сетка и отступы
- Контейнер: max-width 1160px, паддинг 24px (20px мобильный)
- Текстовая колонка внутри секций: max-width 720px; подзаголовки 560px; хиро-текст 620px
- Вертикальный ритм секций: паддинг 72px сверху / 80px снизу; хиро 96px/72px
- Секции разделены линией 1px `#1B2230`
- Радиусы: 2–4px (строгие, почти прямые углы). Без теней и градиентов (тень только у попапа карты)

### 3. Секция / 01 — Чеклист «До вылета» (id: sec-pre)
Механика (общая для /01 и /02, один переиспользуемый компонент `ChecklistSection`):
- **Сегмент-контрол «Кратко / Подробно»**: рамка 1px border, radius 3px; активная кнопка — фон `#1B2230`, текст bright; неактивная — прозрачная, text-faint. «Кратко» — карточки-описания скрыты; «Подробно» — раскрыты все. Клик по названию пункта переопределяет состояние конкретного пункта (toggle).
- **Тумблер «Скрыть выполненное»**: пилюля 30×16px; выкл — рамка border-strong, кноб 10px text-faint слева; вкл — рамка accent, фон `rgba(230,57,70,0.22)`, кноб accent справа. Переход 0.2s.
- **Категория**: заголовок H3 + счётчик «X/Y» (моно 11px) справа; под ними прогресс-линия 2px: трек `#1B2230`, заполнение accent, `transition: width 0.35s ease`.
- **Строка пункта**: разделитель снизу 1px divider; паддинг 13px 0; flex gap 12px. Чекбокс 18×18px radius 3px: пустой — рамка border-strong; отмечен — фон+рамка accent, галочка ✓ 12px цветом bg. Название — кнопка, при отметке: цвет text-faint + line-through. Метка дедлайна справа: моно 11px, рамка 1px border, radius 2px, паддинг 2px 7px («за 2 мес» и т.п.).
- **Карточка-пояснение**: раскрывается кликом по названию, паддинг слева 32px, max-width 600px, 13.5px/1.65 text-muted, анимация fade+slide 0.25s.
- **«+ добавить пункт»** в конце категории: текст-кнопка моно 12px text-faint (hover accent). Клик — инлайн-форма: инпут (фон bg-raised, рамка border, radius 3px) + кнопки «Добавить» (фон accent, белый текст) и «Отмена» (рамка border). Enter — добавить, Escape — отмена. Пользовательские пункты — полноценные (чекбокс) + кнопка удаления «×» (text-faint, hover accent). Стартовые пункты удалять нельзя.

Полное наполнение (5 категорий, 22 пункта с дедлайнами и описаниями) — в `data.js`, ключ `pre`.

### 5. Секция / 03 — Маршрут на карте (id: sec-map)
Layout десктоп: grid `minmax(0,1fr) 360px`, gap 20px. Карта высотой 560px, рамка 1px `#1B2230`, radius 4px. На ≤900px: одна колонка, карта 60vh, панель под картой.

**Лента дней** (flex wrap, gap 8px): кнопка «Весь маршрут» + 10 кнопок «Д1 Токио»… Кнопка: radius 3px, паддинг 7px 12px, моно 12px, точка-индикатор 8px цветом города; активная — рамка accent + фон accent-tint + текст bright; неактивная — рамка border, text-dim.

**Сводка дня** под лентой (моно 12px text-dim): «Д2 · 4 точки · ~6 ч на ногах · транспорт ~¥300»; в режиме «Весь маршрут»: «34 точки · 10 дней · 4 города · транспорт всего ~¥X». Часы = сумма `durMin` точек, стоимость = сумма `cost` сегментов.

**Карта** (Leaflet 1.9.4 CDN):
- Тайлы: CartoDB dark_matter `https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png`, subdomains `abcd`, attribution OSM+CARTO.
- Маркеры — `L.divIcon`: круг 12px цвета города, рамка 2px bg. В режиме дня маркеры дня — 22px с номером порядка посещения (моно 11px bg), остальные приглушены (`#242C3B`, opacity 0.5).
- Линии: в режиме дня — сплошная polyline цветом города (weight 2) через точки дня + `flyToBounds(pad 0.3, 0.8s)`; в режиме «Весь маршрут» — пунктирные линии только между точками разных городов (переезды).
- Попап: фон `#121826`, рамка border, radius 4px; название (600 14px bright), строка «Д2 · прибытие 9:00 · 1,5 ч» (моно 11px), описание (12.5px text-muted).
- Инициализация один раз (useRef + useEffect), при смене дня обновляются иконки/линии/зум без пересоздания карты.
- Fallback: при >5 подряд tileerror карта накрывается заглушкой — текстовый список всех точек (день · название · время); при восстановлении тайлов — убирается.

**Панель дня** (360px, max-height 560px, overflow auto, рамка+radius как у карты):
- Режим «Весь маршрут»: заголовок «Выберите день» + список 10 дней (метка Дx цветом города · город · название дня), клик выбирает день.
- Режим дня: кикер «Д2 · ТОКИО» (моно 11px uppercase цветом города), название дня (20px 700), сводка. Далее вертикальный таймлайн: точка = grid `48px 1fr` — время (моно 12px accent) · название (14px 600) · «1,5 ч на месте» (моно 11px faint) · описание (12.5px muted); hover — фон bg-raised; клик — `flyTo(coords, 15)` + открыть попап. Между точками транспортный сегмент с отступом слева 62px: бейдж режима (ПЕШКОМ/МЕТРО/JR/СИНКАНСЭН/АВТОБУС/КАНАТКА/ЭКСПРЕСС — моно 11px, рамка border, radius 2px) + «линия · время · стоимость» (¥ с пробелами-разделителями; 0 → «бесплатно» или note «по Free Pass»; note «≈» → префикс «~»).

Данные: `data.js`, массив `days` — 10 дней, 34 точки, у каждой пары соседних точек есть сегмент `legs[i]`.

### 6. Секция / 04 — Экспорт (id: sec-export) + футер
Три кнопки: «Скопировать (MD)» / «Скачать .md» / «Печать / PDF». Стиль: прозрачные, рамка 1px border-strong, radius 3px, паддинг 12px 20px, моно 12px uppercase letter-spacing 0.08em; hover — рамка и текст accent. После копирования лейбл на 2s меняется на «Скопировано ✓».
- MD-экспорт: заголовок, оба чеклиста как `- [x] / - [ ]` с дедлайнами курсивом (включая пользовательские пункты), маршрут по дням: `- **9:00** Название (1,5 ч) — описание` + вложенно `→ ТЕГ линия · время · стоимость`.
- Скачивание: Blob `text/markdown`, имя `japan-kit.md`.
- Печать: `window.print()`; print-стили скрывают всё приложение и показывают отдельный светлый документ (белый фон, чёрный текст, ☑/☐ вместо чекбоксов, карта заменена текстовым списком дней).

Футер: верхняя граница 1px, моно 11px text-faint: «JAPAN KIT · личный планировщик · всё сохраняется локально» / «Токио → Хаконэ → Киото → Нара → Осака».

## Interactions & Behavior
- Плавный скролл по якорям из хедера; подсветка активной секции по scroll (порог: top секции < 170px).
- Анимации: раскрытие карточек и инлайн-формы — fade + translateY(−4px) 0.2–0.25s ease; прогресс-бар width 0.35s; чекбокс/тумблер/кнопки — transition 0.15–0.2s; карта — flyTo/flyToBounds 0.7–0.8s.
- Hover: строки панели дня и списка дней — фон bg-raised; кнопки экспорта и «+ добавить» — accent.
- Пустых состояний нет — всё стартовое наполнение в `data.js`.

## State Management
- `checked: {itemId: bool}` — отметки обоих чеклистов
- `custom: {catId: [{id, label}]}` — пользовательские пункты
- `modes: {pre|arr: 'brief'|'detail'}`, `hideDone: {pre|arr: bool}`
- `day: string|null` — выбранный день (null = весь маршрут)
- `expanded`, `adding`, `addText` — эфемерные (не сохраняются)
- Персистентность: всё кроме эфемерного — в `localStorage` под ключом `japankit_v1`, запись при каждом изменении, чтение при инициализации. Если localStorage недоступен (try/catch) — молча работать в памяти.
- Данных с сервера нет; вся модель — статическая константа.

## Критерии готовности
- Счётчики хедера совпадают с реальным числом пунктов (включая добавленные).
- У каждой пары соседних точек дня есть транспортный сегмент.
- Клик по дню зумит карту и синхронно обновляет панель; клик по точке панели центрирует карту и открывает попап.
- «+ добавить пункт» работает в каждой категории обоих чеклистов; свои пункты удаляются, стартовые — нет.
- На 375px ничего не разъезжается: одна колонка, карта 60vh, счётчики хедера скрыты.
- Печать даёт светлый документ без карты.
